# DivIDEo Studio

Запуск: **DivideoStudio.exe**. Windows x64 с .NET Framework 4.5 или новее (в Windows 10/11 входит в систему). Установка не требуется. FFmpeg, FFprobe и исходный конвертер встроены в EXE; при первом обращении распаковываются в `%TEMP%\DivideoStudio-tools-1.0`.

1. Перетащите видео на EXE или в окно программы, либо нажмите «Открыть».
2. На вкладке «Файлы» выберите путь результата. По умолчанию DVO создаётся рядом с исходником.
3. «Фрагмент»: исходный кадр показан над временной шкалой. Нажмите или перетащите верхнюю дорожку, чтобы выбрать момент видео; стрелки ←/→ перемещают позицию на 0,04 секунды. Два синих маркера нижней дорожки задают начало и конец сохраняемого фрагмента. Кнопки «Начало здесь» и «Конец здесь» устанавливают границу по текущей позиции. Время отображается как `чч:мм:сс.мс`: две минуты — `00:02:00.000`. Можно вводить `02:00` или `00:02:00.000`; Enter либо выход из поля применяет значение. Конец и длительность связаны. Лимит кадров 0 означает весь выбранный фрагмент; положительный лимит дополнительно сокращает его.
4. «Геометрия»: обрежьте стороны в пикселях исходника. В исходном кадре удаляемые области сразу затемняются, зелёная рамка показывает оставшуюся часть. Включите «Показать результат обрезки и вписывания (4:3)», чтобы увидеть оставшуюся картинку с выбранным вписыванием, заполнением или растяжением. Этот переключатель меняет только способ предпросмотра; сама обрезка всегда применяется к экспорту. На вкладках «Фрагмент» и «Геометрия» показывается один и тот же выбранный исходный кадр. Выход всегда 256×192, 25 fps — формат проигрывателя DivIDEo.
5. «Изображение»: цвет/моно, дизеринг 1/2/4, бордюр 0–7, контраст, уровень яркости. Название для меню Spectrum ограничено 32 символами ASCII. Необязательный титр поддерживает кириллицу и выводится внизу изображения на протяжении выбранного фрагмента. Очень длинный титр может выйти за края кадра.
6. «Звук»: выберите дорожку, множитель громкости или тишину. Аудио сводится в mono; файл без звука тоже поддерживается.
7. «Предпросмотр»: сохранён отдельный просмотр настоящего DVO у начала фрагмента, с цветом и дизерингом Spectrum. После изменения параметров нажмите кнопку обновления. Исходный кадр на вкладке «Фрагмент» обновляется автоматически после перемещения ползунка, без кодирования в DVO. Оба просмотра покадровые, без воспроизведения звука.
8. Нажмите «Конвертировать в DVO». При замене существующего файла программа спросит подтверждение. Кнопка «Отмена» прерывает обработку; существующий результат сохраняется до успешного завершения новой конвертации.

## Практические замечания

- Входные MP4, MKV, AVI, MOV, WebM и другие форматы читает встроенный FFmpeg 7.0.2. Частота кадров автоматически становится 25 fps.
- Временное несжатое видео занимает примерно **225 МБ на минуту** выбранного фрагмента на диске с `%TEMP%`. Временные файлы задания удаляются после завершения или отмены. При аварийном завершении приложения могут остаться папки `DivideoJob-*`.
- Сначала полезно проверить несколько секунд и подобрать яркость и контраст по предпросмотру. Начальные значения — контраст 5.5, яркость 0.3.
- Требуются Spectrum 128K и **DivIDE**, либо соответствующий эмулятор и проигрыватель. DivMMC исходным проектом не поддерживается. На реальном накопителе DVO должен лежать без фрагментации.
- Приложение проверяет заголовок, пакеты и границы кадров готового DVO. Аппаратное воспроизведение на Spectrum в рамках разработки GUI не проверялось.

## Исходники и сборка

`src/DivideoGui.cs` — интерфейс, подготовка, запуск конвертера, проверка DVO и декодер предпросмотра. `src/EditorControls.cs` — поля времени, временная шкала и просмотр обрезки. `build.ps1` собирает EXE штатным компилятором .NET Framework (csc.exe) с автоопределением пути к FFmpeg.

Встроенные проверки: `powershell -ExecutionPolicy Bypass -File tests/run-tests.ps1` либо `DivideoStudio.exe --self-test ПОЛНЫЙ_ПУТЬ_К_ПАПКЕ`. Создают синтетические видео, проверяют три режима геометрии, моно/цвет, дизеринг, титр, отсутствие звука, лимит кадров, отмену процесса и элементы GUI.
