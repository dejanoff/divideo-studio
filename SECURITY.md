# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in DivIDEo Studio, please report it responsibly:

- Do **not** open a public issue.
- Please report vulnerabilities via [GitHub Security Advisories](https://github.com/dejanoff/divideo-studio/security/advisories/new) or contact the maintainer directly.
- Include detailed steps to reproduce the issue, along with proof-of-concept files if applicable.
- You will receive an initial response within 48 hours, followed by updates on progress toward a resolution.
